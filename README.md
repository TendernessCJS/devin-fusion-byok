# Devin Fusion BYOK

一个 Devin 用户扩展：把你自己的模型 API（BYOK）接入 Devin 原生模型列表，并把这些模型组合进 Devin 官方的 Fusion 卡片（Lead + Sidekick）使用。

> 本仓库是 [kuobibulaien/devin-fusion-byok](https://github.com/kuobibulaien/devin-fusion-byok) 的 fork。下载与自更新均指向本仓库的 Release。

- 不修改 Devin 应用本体，不需要重新签名，也不安装证书或改系统代理。
- 支持 OpenAI Responses、OpenAI Chat Completions、Anthropic Messages 三种接口。
- 第三方模型可以单独用；勾选成 Fusion 角色后，也可以和其他第三方模型或官方模型组合，直接在 Devin 模型选择器的 Fusion 卡片里选。

## 安装

1. 从 [Releases](https://github.com/TendernessCJS/devin-fusion-byok/releases/latest) 下载 `devin-fusion-byok-<版本>.vsix`。
2. 在 Devin 命令面板运行 **Extensions: Install from VSIX…** 选择该文件，或在终端执行：

   ```bash
   /Applications/Devin.app/Contents/Resources/app/bin/devin-desktop --install-extension devin-fusion-byok-<版本>.vsix
   ```

3. 重载窗口（**Developer: Reload Window**）或新开一个 Devin 窗口。

之后可以在面板 **设置 → 插件更新** 里检查并一键安装新版本（目前仅 macOS）。

## 快速开始

点击右下角状态栏 **Fusion BYOK**，或在命令面板运行 **Fusion BYOK：控制面板**。

1. **模型** 页：添加供应商，填写名称、API 地址、密钥，选择接口类型。
   只填域名时会自动补 `/v1`，写了路径则按原样使用（如 `https://your-gateway.example/openai`）；弹窗会显示实际请求地址。
2. 点 **导入模型**，勾选需要的模型后点 **导入**。
3. **Fusion** 页：勾选哪些模型可以当 Lead、哪些可以当 Sidekick。导入的模型默认已勾选，官方默认 Sidekick 本来就能用，不需要你补充添加。
4. 在 Devin 模型选择器里打开 **Fusion** 卡片，用 Lead / Effort / Sidekick 三个下拉直接选组合。

视图由 Devin 自己负责，插件只保证候选齐全。列表没更新时，点面板右上角的 **重载窗口**（不影响其他窗口）；仍无效再点 **重启 Devin**（关闭所有窗口后自动重开，诊断日志在插件全局存储目录的 `restart.log`）。

## 功能

| 标签页 | 内容 |
| --- | --- |
| 模型 | 管理供应商和模型：启停、改显示名、上下文长度、思考档位 |
| Fusion | 选择哪些模型出现在官方 Fusion 卡片的 Lead / Sidekick 下拉里 |
| 用量 | 本机请求统计：首字时间、输出速度、token 用量 |
| 目标 | 目标模式开关（默认关闭）与 `/goal` 命令说明 |
| 对外提供 MCP | 检测账号、开关（默认关闭）、复制给其他工具的配置 |
| 设置 | 运行状态与注入健康（后台服务 / 目录桥 / 推理入口 / CLI 缓存 / 桌面目录 / 会话模型）、自动继续、官方模型显示、CLI 缓存刷新、插件更新 |

一些默认行为：

- 新模型默认上下文 272,000 tokens、最大输出 131,072 tokens，可逐个修改。
- GPT-5/6、o 系列、Claude Opus/Sonnet/Fable 4.6+ 自动提供 Low～Max 思考档位；实际是否生效取决于供应商。
- 你在 Fusion 卡片里选的组合会被记住：Devin 让你选中一个锁定的官方组合时，插件用它回退。你自己（或 Devin）在官方卡片里做的选择不会被插件改掉。
- 状态栏的 **上下文** 入口可以查看所选会话的上下文占用和最近请求的速度。
- `OpenAI Responses` 供应商会**自动**启用推理状态通道（无开关）：请求带 `store:false` 与 `include:['reasoning.encrypted_content']`，插件把该轮推理/工具输出项经签名通道（ACP 字段 10）随会话带回，下一轮在作用域（供应商/地址/密钥/模型）与内容校验一致时按原序回放。这是官方对无状态多轮推理模型的要求——与 Anthropic 思考签名回放对称。若某网关拒绝这些参数并点名 `store`/`include`，插件会自动去掉该字段重试一次。
- 为什么用信封通道而不是 ID 关联：`previous_response_id` 在本机直连官方的转发面（Proxy）上实测回 400（`store:true` 本身被接受），因此多轮推理延续**只能**靠无状态回放——**直连官方的转发面才是这个通道的目标场景**，它会返回真实 `encrypted_content`（带推理时实测约 3.4–3.6 KB）。
- 各面的实测差别：DeepSeek 也产出带 `encrypted_content` 的 reasoning item，但仅 **38 字符且 `summary` 为空**，形似占位——回放它既不报错，也不减少推理开销，即在该面上**既无收益也无害**；Moonshot 的 reasoning item **不带** `encrypted_content`，对它整轮都发不出信封。实测「回放」与「省略推理」在 DeepSeek、Proxy 上**均返回 200** 且答案一致，所以这个通道的收益是**语义对齐**，不是修复可用性故障。
- 已知风险：携带通道在真实尺寸上尚未验证（实测最高约 42 KB，已证闭环仅 36 B），而状态损坏在官方面上的表现是难以归因的 502。

### 用量监控

- 只统计插件接管的 BYOK 请求，以插件请求日志为用量主账；会话归属只读查询 Devin 的工具状态表，唯一命中才归属。官方模型的转发请求不计入此处。
- 最多最近 5000 条保留记录可供筛选，汇总覆盖当前时间与会话范围的全部样本，表格每页显示 100 条；会话标题仅视觉省略，悬停提示保留完整文本。原生下拉菜单的选项 tooltip 是否显示取决于系统。
- 时间区间默认当月，可选上月、最近 7 天（含今天）、全部保留记录或自定义日期。按本机时区和请求 `startedAt` 筛选，开始日包含、结束日包含全天；开始时间按同一时区展示，悬停保留原始时间。切换时间或会话后回到第一页，轮询刷新保持选择。
- 时间筛选同时作用于明细、token、速度、异常排除与归属计数，仅作用于“用量”页，不改变上下文详情的最近请求。历史可能已被保留上限裁剪，结果可能不完整，非供应商账单；不会自动计算费用或补取已裁剪的数据。
- 记录异步串行追加，正常情况下每额外 250 条压缩一次；正常关闭会刷完队列并保留最近 5000 条。存储异常时保留原日志并提示降级，不覆盖无法读取的文件。
- 归属只查 `tool_call_state`（工具 ID 命中覆盖索引）；不会用时间接近、会话当前模型、正文中出现 UUID 或 `message_nodes` 全表扫描来猜归属。没有可靠关联时保持未归属，歧义单独标注。
- 首数据事件是首个进入监控的 SSE 数据事件，不是 HTTP 响应头。首数据后吞吐与含等待的请求吞吐都使用有效输出总 token（含推理和工具）；正文 TPS 仅在信息足够且不含工具时计算，汇总展示最近一条有效样本而非平均值。失败、取消请求的有效已上报用量仍计入用量和吞吐。
- 异常用量保留在明细但从 token 和吞吐汇总中排除，面板显示排除数量；请求数和时间统计不因此删除样本。缓存/推理 token 是输入/输出的子集，不应再次加到总量。数据库消息树可重复表示同一消息，不能用节点行数汇总请求或 token。

## 目标模式（Goal）

默认关闭。在控制面板「目标」页打开开关后，Devin 聊天框里才会出现 `/goal`；关闭时正在推进的目标会暂停。打开后在聊天框直接输入命令，让模型围绕一个目标一轮轮自动工作，直到它提交带证据的完成报告。

| 命令 | 作用 |
| --- | --- |
| `/goal <目标>` | 在当前对话启动目标，已有目标时替换 |
| `/goal` | 查看目标、状态、已运行轮数和最近进展 |
| `/goal pause` | 暂停 |
| `/goal resume` | 继续；到上限时再追加 10 轮 |
| `/goal clear` | 清除目标 |

- 把“怎样算做完”写进目标，例如：`/goal 让 test/auth 里的测试全部通过，并保持 lint 干净`。
- 模型每轮通过专用报告命令提交进展；报告“完成”并附证据后目标自动结束。只在回复里说“做完了”不算。
- 默认最多 10 轮，总共最多 100 轮。遇到权限确认、取消、连续两轮没有报告、连续三轮没有进展或窗口重载时会停下。
- 你中途插话后，等你这一轮结束，目标会自动继续。
- 每一轮都是正常计费的模型调用；空闲时查看和控制命令也会产生一次很短的回复。运行中查询状态直接由插件显示，不新增模型调用，也不打断原任务。


## 对外提供 MCP（实验性）

把 Devin 的三项检索能力提供给其他支持 MCP 的 Harness：

- `code_search`：自然语言代码检索，返回相关文件、行号和代码片段（即 Devin 内部的 code_search / Fast Context，**不是普通关键词搜索**；旧名 `fast_context_search` 仍可调用）；
- `web_search`：网页搜索，返回标题、地址和简短摘要；
- `web_read_url`：读取一个公开 https 网页的正文文字，常用来打开搜索结果。

三项能力使用同一个 Devin 已登录账号，受账号与团队的网页搜索开关约束。

打开 **Fusion BYOK 控制面板 → 对外提供 MCP** 标签页，选择允许搜索的项目，对外 MCP **默认关闭**，按面板三步操作：① **检测账号**，分别确认三项能力是否可用；② 代码搜索可用后才能打开 **开启对外 MCP** 开关；③ 选择项目，复制 **提示词**（推荐，发给目标 Harness 里的 Agent，它会自己合并配置并验证）或 **配置 JSON**。开关关闭时，已接入的工具列不出任何工具、调用会返回 `mcp_disabled`，独立启动会直接退出。复制出的配置使用本机安装路径，只适用于当前电脑；它指向插件存储目录里的固定入口 `fusion-mcp.cjs`，插件升级后无需重新配置。也可以在命令面板运行 **Fusion BYOK：对外提供 MCP 接入配置**（同样需要先开启）。

也可以直接使用源码入口：

```json
{
  "mcpServers": {
    "fusion-fast-context": {
      "command": "/absolute/path/to/node",
      "args": [
        "/absolute/path/to/devin-fusion-byok/src/fast-context/server.cjs",
        "--root",
        "/absolute/path/to/project"
      ]
    }
  }
}
```

- 需要 **Node.js 22.16+（推荐 24 LTS）** 和 ripgrep；自动查找 PATH 或 macOS Devin 自带的 ripgrep，也可通过 `FUSION_FAST_CONTEXT_RG` 指定其绝对路径。不依赖正在运行的 Devin 窗口。
- 提供 `code_search`（`query`、`max_turns` 1–5、`max_results` 1–20、`include_content`）、`web_search`（`query`、`limit` 1–20、可选 `domain`）、`web_read_url`（`url`，仅 https）与 `fast_context_status`。默认最多三轮搜索、另一次最终答案请求；遇到模型格式错误，最多追加一次纠正请求，不猜测执行。每次代码搜索总时限 120 秒，同一 MCP 进程同一时间只接受一次代码搜索，支持取消；网页调用互不阻塞，各自最长约 60 秒。
- 网页搜索走官方接口；网页读取在确认账号网页搜索开关后，在本机抓取正文并提取可读文字（与 Devin 一致：官方不返回正文）。只接受 https，最多跟随 5 次 https 跳转，拒绝内网地址与本地域名，不执行脚本、限制大小。团队或账号关闭网页搜索时返回 `web_search_disabled`，不绕过。
- 面板「检测账号」会读取本机 Devin 登录，向官方服务确认代码搜索、网页搜索、网页读取三项是否可用，只显示结论，不显示也不保存凭证。
- 使用本机 Devin 桌面的已有登录记录；也可由环境变量 `WINDSURF_API_KEY` 提供凭证。不把密钥写入生成的配置，不提供提取密钥工具。**使用官方账号权限及额度，不走 BYOK 供应商**；账号或团队禁用时直接报错。
- 问题、目录信息和选中的代码片段会发往官方服务。只搜索启动时指定的项目；可追加 `--exclude pattern`。默认遵守 ignore 规则，并排除常见凭证文件、依赖、构建产物、软链接和硬链接。**这不是秘密识别器**：不要选择包含敏感内容的项目，额外排除私有目录。
- 仅在内存中创建只读快照，不运行模型给出的 shell 命令，不写入项目。默认检查最多 3,000 个候选文件、8 MiB 文本、每文件 512 KiB、20 万行；被限制的结果明确标记 `partial`。读取失败、二进制等跳过数量另列。大仓库应选择更小的项目根目录。
- 检索是尽力而为，不保证找全；返回前核对文件内容与行号，修改代码前仍需自行复查。服务内部接口变化可能导致不兼容，错误不会伪装成“没找到”。

配置命令只打开一份未保存的 JSON，面板只把提示词或配置复制到剪贴板，插件本身不自动注册其他 Harness、不重启应用、不启动后台监听端口。单独运行的 MCP 由目标 Harness 管理，停用 VS Code 插件不会结束它；停用 MCP 请在目标 Harness 中移除或关闭该服务。

## 自动继续（默认关闭）

在 **设置** 页可分别开启：

- **服务商出错时自动重试**：遇到 “Provider response could not be completed”、“Provider response timed out after Ns/Nms” 或匹配的临时错误（408、429、500、502、503、504）时自动发送 `continue`，间隔 2～30 秒递增。连续错误最多自动重试 5 次，重试窗口最多 10 分钟；任一上限触发后停止并提示你检查服务商、手动继续。恢复成功并转入待办续跑，或开始新的手动回合时，连续错误预算重新计算。此策略与 Goal 的重试策略独立。
- **待办没做完时自动继续**：会话里有未完成的 Plan/Todo、且回合以自然结束（`end_turn`）、达到输出上限或达到回合上限收尾时，自动发送 `continue`；你手动取消、模型拒绝、或待办没有变化时不会续跑，避免空转。开关关闭时完全不续跑。

两项都会产生额外的模型调用。

### 模型列表没更新

Devin 的模型选择器读的是 CLI 在 `~/.cache/devin/cli` 下的按身份缓存。改过供应商或模型之后，如果下拉里少条目、条目形态不对、或还留着已删除的模型，打开 **设置 → CLI 缓存 → 刷新缓存**：插件会把该目录下**属于本插件**的缓存原地重写（原文件留成 `.bak`），不需要重载窗口。可写性按文件内容判定：任何代际的 `model_configs*` 只要信封与载荷校验通过都会原地重写；是 JSON 但格式未适配的会提示「发现未知代际缓存，当前插件未适配，请更新插件」，非 JSON 的历史文件只报为旧版本残留。旁边的「刷新模型目录」把合并后的目录重新提交给桌面端，以原生提交确认为准。

这次检查是**强制**的：自动检查只看 UID 是否齐全，而「UID 齐全但内容过时」（例如模型换了名字、下拉里的选项多余）它看不到，所以按钮会主动重算一遍，只有内容真的有差异才写盘——连按不会反复改动文件。

## 隐私与安全

- 密钥只保存在本机用户配置文件（权限 0600），面板不回显已保存的密钥。
- 模型发现和推理请求拒绝 HTTP 重定向，避免密钥和对话被转发到其它地址；请填写供应商的最终 API 地址。
- 日志只记录模型名、工具名和连接状态，不记录对话正文和密钥。
- 插件通过 `WINDSURF_API_SERVER_URL` 让 Devin CLI 连接本机服务；官方请求仍经正常 HTTPS 发往官方接口。
- 不会解锁账号本来没有的官方模型或权限。
- 更新检查只访问本仓库的 GitHub Releases，安装前校验文件大小、SHA-256 和包内身份，并需要你确认。

## 受限网络（需要代理时）

如果本机直连 GitHub 不通，可以在面板 **设置 → 更新代理** 填写 HTTP/HTTPS 代理地址，让**更新检查和一键安装**走该代理；留空表示直连。

也可以直接编辑插件配置文件（扩展全局存储目录，macOS 通常是 `~/Library/Application Support/Devin/User/globalStorage/local.devin-fusion-byok/config.json`），加入等价的 `updateProxy` 项：

```json
"updateProxy": "http://127.0.0.1:7897"
```

- 支持 `http://` / `https://` 代理地址，可带 `user:pass@` 凭证；保存后立即生效，无需重载窗口。面板中凭据只显示为掩码（如 `http://***@127.0.0.1:7897`），不会进入面板；直接保存掩码不会丢失凭据，输入完整新地址才会替换。
- **只影响更新相关请求**：模型发现使用独立直连传输，推理仍由独立 backend 处理；未配置 `updateProxy` 的更新请求同样使用独立直连传输，不依赖宿主全局 `fetch` 或全局 Agent。不要用 VS Code 的 `http.proxy` 设置或 `HTTPS_PROXY` 环境变量替代 `updateProxy`。
- 代理地址无效时面板会提示 `updateProxy` 配置有误，不影响其他功能。

## 停用与卸载

先在命令面板运行 **Fusion BYOK：停用并恢复连接**，再卸载扩展。这会撤回模型注入，并把插件写过的 Devin 设置恢复原样（你之后自己改过的不动）。已开始的对话沿用原来的设置，停用后请新建对话。

## 从旧版本升级

早期版本用「预设」卡片提供具名组合，现在已由 Devin 官方的 Fusion 卡片取代。升级时插件做过一次性迁移：把原预设用到的 Lead / Sidekick 转成角色勾选（它们仍会出现在 Fusion 卡片的下拉里），并删除配置里已无用的预设字段。原配置的副本仍在扩展全局存储目录下的 `config.json.pre-preset-retirement.bak`，需要找回旧预设时以它为准。迁移逻辑本身已随预设管线一起删除，遗留字段由激活期的配置清理顺带清掉。

原来储存在配置里的默认组合也会保留，并跟随上面这次迁移映射到等价的组合上。

## 已知限制

- 依赖 Devin 当前的内部接口，Devin 大版本更新后可能需要插件跟进。
- 图片输入对所有导入模型都声明为支持，实际能否处理取决于模型。
- 思考档位按模型 ID 规则提供，不是对供应商能力的检测。
- 一键更新和“重启 Devin”目前仅支持 macOS。
